# 🧟 2D Zombie Survival

A browser-based 2D zombie survival shooter built using **HTML, CSS, JavaScript, and HTML5 Canvas**.

Survive endless waves of zombies, manage your health and stamina, collect health packs, and see how long you can stay alive!

      https://unknownsohel.github.io/-2D-Multiplayer-Zombie-Survival/
                       🎮 PLAY THE GAME

## 📌 About the Project

2D Zombie Survival is a top-down survival shooter where the player must fight incoming zombies and survive increasingly challenging waves.

The project was built to practise JavaScript, game loops, collision detection, object handling, keyboard and mouse events, and real-time game mechanics.

It is currently a **single-player game**, with multiplayer functionality planned for a future version.

## ✨ Features

- **Player Movement:** Move around the game arena.
- **Mouse Aiming:** Aim and shoot zombies using your mouse.
- **Multiple Zombie Types:**
  - 🟢 Normal Zombies – Standard enemies.
  - 🟡 Fast Zombies – Faster enemies that can dash.
  - 🔴 Tank Zombies – Larger enemies with higher health.
- **Wave System:** Survive increasingly difficult waves.
- **Health System:** Player health decreases when zombies attack.
- **Stamina System:** Sprint using stamina, which regenerates over time.
- **Health Pickups:** Collect health packs to restore health.
- **Shooting & Reloading:** Use a 30-bullet magazine with a reload timer.
- **Pause System:** Pause and resume gameplay.
- **Scoring System:** Earn points by eliminating zombies.

## 🎮 Controls

| Key / Input | Action |
|---|---|
| `W` | Move Up |
| `A` | Move Left |
| `S` | Move Down |
| `D` | Move Right |
| `Shift` | Sprint |
| Mouse Movement | Aim |
| Left Mouse Click | Shoot |
| `Escape` | Pause / Resume |

## 🚀 Run Locally

You can run this project locally without installing any dependencies.

1. Clone the repository:

   ```bash
   git clone https://github.com/unknownsohel/-2D-Multiplayer-Zombie-Survival.git
   ```

2. Open the project folder:

   ```bash
   cd -2D-Multiplayer-Zombie-Survival
   ```

3. Open `index.html` in your browser.

Alternatively, use the **Live Server** extension in VS Code.
